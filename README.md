# Vantadge Greens · Sales Tracker

Tap-to-sell tracker for the morning juice stall. Sales and ingredient purchases are saved to a Google Sheet.

- `index.html`: the tracker page, served by GitHub Pages.
- `google-sheet/Code.gs`: the Apps Script that connects the page to the Google Sheet.

The Apps Script web app URL is set at the top of the script in `index.html` (`const API = ...`).
